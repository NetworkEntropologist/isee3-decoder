# ISEE-C Telemetry Formats and Telemetry Lists

**International Sun-Earth Explorer – C (ISEE-C)**

| | |
|---|---|
| Document number | 905-TL-3006-01 |
| Revision | C |
| Date | September 8, 1977 |
| Prepared by | Fairchild Space & Electronics Company, 20301 Century Blvd., Germantown, Maryland 20767 |
| Source | ISEE Notebook 18g-2 (scanned PDF, 86 pages) |

ISEE-C was launched in 1978 as ISEE-3. This site is a transcription of its telemetry format document. It covers how the minor and major frames are put together, how the subcommutators are laid out, and what every telemetry word and status bit means in the scientific (normal) and engineering formats.

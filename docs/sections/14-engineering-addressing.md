# XIV. ISEE-C Minor Telemetry Frame Engineering Addressing Format

*Original page 18, Revision C, 9/8/77*

![Section XIV: Minor Telemetry Frame Engineering Addressing Format](../images/sec14-engineering-addressing.png)

This is the [Section X](10-minor-frame-engineering.md) engineering minor frame grid, annotated with the DHU address each word is read from. For example, AI<sub>23</sub> is the accelerometer, AI<sub>0</sub> is ASI 1, AI<sub>8</sub> is ASI 2, DI<sub>0</sub> is DSI, AI<sub>16–31</sub> is an indirect address, and DI<sub>7</sub> is SMH.

Notes on the original:

1. A dark triangle indicates the word gate is generated and used.
2. A light triangle indicates the word gate is generated but not used.

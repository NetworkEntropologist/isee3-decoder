# Appendix B – ISEE-C Scientific Format Telemetry List, Listed by Subsystem/Experiment

*Original pages B-0 to B-32 (including B-3a)*

Appendix B regroups the [Appendix A](../appendix-a/index.md) assignments by subsystem or experiment. It also adds information that Appendix A does not have: analog thresholds, bit-level states, supercommutation, and how experiment data is spread across words and minor frames. The "See B-…, App B" remarks elsewhere on this site link to these pages.

Transcription conventions are the same as for [Appendix A](../appendix-a/index.md). Down-arrows are written out, bracketed remarks are repeated on each row, ditto marks (″) are kept as printed in the Analog Range column, and typos are kept. Long multi-line remarks are broken into lines.
